# IllyChallenge
This was made for the technical challenge. It does not execute SQL, it only builds and prints SQL text.

## What it supports

- `SELECT` queries
- Selecting specific fields
- Dynamic field lists
- Table aliases
- Column aliases
- `INNER JOIN`
- `LEFT OUTER JOIN`
- `RIGHT OUTER JOIN`
- `FULL OUTER JOIN`
- `WHERE` clauses
- Combining conditions with `AND` and `OR`

## How to run

Open the solution in Visual Studio and run the console app.
